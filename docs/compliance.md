# الامتثال لنظام حماية البيانات الشخصية والأمن السيبراني

## ما يوفّره النظام (تحديث 14 — ملف SQL رقم 15)
| المتطلب | أين في النظام |
|---|---|
| سياسة خصوصية وشروط بإصدار وتاريخ (عربي/إنجليزي) | `/privacy` و `/terms` + روابط في تذييل الموقع وصفحة الدخول |
| إشعار وموافقة عند الجمع | خانة موافقة إلزامية في نماذج الحجز والزيارة والخدمات والتوظيف، وخانة تسويق اختيارية منفصلة |
| موافقة المستخدمين المسجلين | تُطلب عند أول دخول وعند كل إصدار جديد للسياسة |
| سجل الموافقات | جدول `consents` (منح وسحب، لكل غرض ونسخة سياسة وقناة) |
| سحب الموافقة بسهولة | صفحة "بياناتي وخصوصيتي" (`/account/data`) |
| حق الحصول على نسخة | زر "تنزيل بياناتي" (ملف JSON فوري) |
| حق التصحيح والحذف والاعتراض | طلبات من `/account/data` بمهلة 30 يومًا، وتُعالج من لوحة الإدارة ← الخصوصية والامتثال |
| حذف بيانات زائر بدون حساب | لوحة الإدارة ← الخصوصية والامتثال ← حذف بيانات زائر |
| سجل أنشطة المعالجة | لوحة الإدارة ← الخصوصية والامتثال |
| خطة الاستجابة للتسرب (72 ساعة) | لوحة الإدارة ← الخصوصية والامتثال |
| سجل التعديلات | جدول `audit_log` للجداول الحساسة (أرقام الهوية والحسابات البنكية لا تُحفظ قيمها) — يقرأه الأدمن فقط ويُحفظ 5 سنوات |
| مدد الاحتفاظ والحذف التلقائي | السير الذاتية وطلبات الزوار والإشعارات تُحذف تلقائيًا يوميًا حسب المدد في الإعدادات |
| التحقق بخطوتين | `/account/security` لكل المستخدمين، مع خيار إلزام الإدارة والموارد البشرية |

## تفعيل التحقق بخطوتين في Supabase
Supabase → Authentication → Multi-Factor → فعّل **TOTP** (مفعّل افتراضيًا في أغلب المشاريع).
بعدها: كل مستخدم يفعّله من "حسابي ← الأمان والتحقق بخطوتين".
لا تفعّل خيار "إلزام الإدارة والموارد البشرية" إلا بعد أن يفعّل الأدمن التحقق بخطوتين في حسابه.

## مهام إدارية على الشركة (خارج النظام)
1. تعيين **مسؤول حماية البيانات** وإدخال اسمه وبريده من لوحة الإدارة ← الخصوصية والامتثال.
2. إدخال **مكان استضافة البيانات** (منطقة مشروع Supabase: Settings → General → Region).
3. **التسجيل في منصة حوكمة البيانات الوطنية** لدى سدايا إذا انطبق (معالجة بيانات حساسة مثل المرفقات الصحية للإجازات المرضية).
4. مراجعة **سياسة الخصوصية والشروط** من المستشار القانوني للشركة واعتمادها.
5. الاطلاع على اتفاقيات معالجة البيانات (DPA) لدى Supabase و Vercel ومزود الرسائل.
6. متابعة **مسودة تعديلات نظام حماية البيانات** (توطين البيانات داخل المملكة) والاستعداد للنقل لمزود سحابي محلي إذا اعتُمدت.
7. ضوابط الهيئة الوطنية للأمن السيبراني للقطاع الخاص (NCINCC-1:2025): سياسات مكتوبة، توعية الموظفين، اختبار اختراق دوري.

> هذا الملف ملخص تشغيلي وليس استشارة قانونية.
